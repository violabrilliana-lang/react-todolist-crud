# TodoList React 19 (CRUD) - Bootstrap

Aplikasi TodoList interaktif dengan fitur CRUD (Create, Read, Update, Delete) yang dibangun menggunakan **React 19** dan **Bootstrap 5**.

## 📸 Tampilan Aplikasi
![alt text](<Screenshot 2026-11-09 174935.png>)

## ✨ Fitur Utama
- **Create**: Menambahkan tugas baru dengan tingkat prioritas dan status.
- **Read**: Menampilkan daftar tugas secara rapi dengan badge warna.
- **Update**: Mengedit judul, prioritas (High, Medium, Low), dan status tugas.
- **Delete**: Menghapus tugas dari daftar.
- **Priority Badge Color**: 
  - 🔴 High (Merah)
  - 🟡 Medium (Kuning)
  - 🟢 Low (Hijau)
- **Status Indicator**: To Do, In Progress, dan Done.

## 🛠️ Teknologi yang Digunakan
- **React 19**
- **Bootstrap 5** & **Bootstrap Icons**
- **Vite**
